# 💻 Desafio Técnico — Target Sistemas

Repositório com soluções desenvolvidas em **Python** para um desafio técnico de programação.

O projeto reúne exercícios de lógica, manipulação de dados, cálculos e resolução de problemas, demonstrando raciocínio lógico e fundamentos de programação.

## 🐍 Tecnologia

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 📁 Estrutura

```text
Pergunta01.py
Pergunta02.py
Pergunta03.py
Pergunta04.py
Pergunta05.py
faturamento.json
```

Cada arquivo `PerguntaXX.py` contém a solução de uma etapa do desafio. O arquivo `faturamento.json` é utilizado em um dos exercícios de análise de dados.

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/Lehguto12/Target-Sistemas.git
cd Target-Sistemas
```

Execute o exercício desejado:

```bash
python Pergunta01.py
```

Substitua o nome do arquivo pela questão que deseja executar.
